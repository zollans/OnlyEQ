# OnlyEQ 1.3.0

- Adds separate left and right EQ: switch any band to L or R only with the toggles on its card, and the curve splits to show each channel. Equalizer APO `Channel:` blocks in REW and AutoEq exports now import as-is.
- Adds **Export…** next to Import: save the current preset as Equalizer APO / AutoEq text or OnlyEQ JSON. Thanks to @jayeshmann.
- Smoother EQ curves, a highlighted shape for the selected band, and a band strip that fades at its edges instead of cutting off the last card.
- Bypass no longer jumps playback to full volume on devices without hardware volume control.
- Moves an unreadable preset file aside instead of overwriting it, so a damaged file can no longer wipe your presets.
- Imports filter lines that have no Gain value (high-pass, low-pass and similar), which were silently dropped before.
- Typing into a field shown as "1.5 kHz" now edits the exact value instead of reading it as 1.5 Hz.
- Removes memory allocation from the audio thread, and fixes Reset Everything, the Show latency setting, apps excluded after launch, and Command shortcuts on non-Latin keyboard layouts. Thanks to @maltemoeser.
